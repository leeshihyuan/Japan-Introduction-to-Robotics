# I．本書紹介（最終稿）

『ロボティクス入門：機構・知覚・制御・身体性AI』は、台湾の工学教育環境を中核に据えて独自に編纂した大学教科書であり、次の四つの根本的な問いに答えることを目的とする。

1. ロボットの身体は、どのように設計されるのか。
2. ロボットは、自らがどこにいるかをどのように認識するのか。
3. ロボットは、どのように動作を計画し、その身体を制御するのか。
4. ロボットは、視覚・言語・人工知能を通して世界をどのように理解するのか。

本書は、以下の五つの流れを統合して構成されている。第一に、Craig『ロボティクス―機構・力学・制御』（原著『Introduction to Robotics: Mechanics and Control』）に代表される米国型の数理的骨格、すなわち空間の記述、運動学、ヤコビ行列、動力学、軌道生成および制御である。第二に、図解、システム構成、段階的な説明を重視するドイツの教科書の教育方法である。第三に、ベルリン工科大学におけるToussaintの講義資料が扱う現代的主題、すなわちサンプリングベース経路計画、確率的状態推定、SLAM、最適制御、強化学習、把持および脚式移動である。第四に、MIT、CMU、ETH Zürichの授業に見られるシステム統合、自律ロボット・アーキテクチャ、ROS 2およびロボット学習である。第五に、台湾の産業事例と、小学校のクラブ活動から大学の専門教育までを連続的につなぐ、スパイラル型ロボティクス教育体系である。

## 本書の特色

1. **米国型の数理的骨格 × ドイツ型の図解教育 × 台湾の実践事例**  
   主要概念ごとに、原則として実物写真、システム構成図、座標系の模式図、中心となる数理モデル、数値例題、プログラム例、実習活動、および「ロボット教授の講義」と題する物語を配置する。

2. **十分な理論的深度**  
   最適制御とRiccati方程式、可制御性とLyapunov安定性、力閉包に基づく把持理論、ZMPおよび受動歩行を、それぞれ独立した章として扱う。大学院進学前の準備教育に達する深度を備え、試験問題として出題でき、導出過程も評価できる構成とする。

3. **身体性AIの最前線**  
   ROS 2、ロボット学習、LLM／VLM／RAG、VLA、Diffusion Policyおよび世界モデルを計5章で扱い、2026年に本格化するロボット基盤モデルの潮流へ接続する。さらに、中国語（華語）および台湾語（台語）による音声対話という台湾独自の特色も取り入れる。

4. **「ロボット教授の講義」から始まる物語**  
   定着後に自らの脳を消化する尾索動物、アポロ13号のジンバルロック、Monty Hallの三つの扉問題、手袋の思考実験、坂道を自ら歩き下りる木製玩具などを取り上げる。各章はまず具体的な情景から始まり、その後に理論へ進む。

5. **段階別に読める構成**  
   物語による入門層（小中学生のクラブ活動）、工学基礎層（高校生・大学1年生）、専門数理層（大学専門課程・大学院進学前）という三層を設ける。高度な導出はコラムにまとめ、初学者が数式のために学習を中断しない構成とする。

6. **シリーズ専門書への導線**  
   第25章のSLAMから、本シリーズの全31章からなる専門教科書『地図構築と同時自己位置推定（SLAM）』へ直接接続し、「入門書 → 専門書」という学習経路を形成する。

7. **クラブ活動向け工作教材12編**  
   振動ロボットからVLM視覚言語ロボットまでを扱う。各編に「スパイラル接続」欄を設け、本文の対応章を明示する。小学生が製作する一台一台のロボットを、大学で学ぶ理論への入口と位置づける。

## 最終統合方針

本最終稿は、全6編からなるシステム上の骨格を基礎とし、次の四つの理論的な柱を補強した。

1. 制御理論を、非線形制御、最適制御とRiccati方程式、可制御性と安定性の3章に再編する。
2. 把持とマニピュレーションを独立した章とする。
3. 脚式ロボットを独立した章とする。
4. 世界主要大学のカリキュラム紹介を第2章に統合する。

さらに、付録12編すべてにスパイラル接続の設計を加えた。統合後の全書は、全36章と付録12編で構成される。

数式を少なく、図を多くし、実際に製作でき、成果を展示できる内容とする。各編には、材料一覧、段階別の組立図、ブロックプログラムまたはサンプルコード、授業内チャレンジ、および「スパイラル接続」欄を設ける。この欄では工作ロボットと本文の理論章との対応を示す。クラブ活動の児童・生徒が成長後に本書を読み返したとき、小学生の頃に大学レベルの実験をすでに体験していたことに気づける構成とする。
